# Gemini API free tier (no billing) for all LLM analysis

All AI analysis uses the Gemini API (Flash-class models) on the free tier with no billing account attached, guaranteeing zero cost. Quota exhaustion (HTTP 429) degrades the pipeline gracefully and resets automatically. If free-tier data usage for model improvement later becomes unacceptable, the Google AI Pro subscription's $10/month Google Cloud credits provide a paid-tier upgrade path without out-of-pocket spend.
