# ADR-0012：穩定導向風險調整評分（成長品質 + 穩定持續 + RR）

狀態：已接受（2026-08-02）

## 情境

使用者要求評分重點改為：**穩定獲利 > 高獲利、穩定持續獲利 > 短期高獲利、穩定成長 > 高波動**；高槓桿／高風險基金不適合長期投資。

現行評分（ADR-0003）中動能分佔 0–85（85%），只獎勵漲幅：黃金（RR5）、生技／科技（RR4）等波動大的產業／商品型基金，只要近期單期大漲即擠進前段，與「穩定型優先」衝突。實測：黃金基金「3Y +180% 但 1M −12%」與穩定型基金同分。

## 資料調查

- TDCC 基金搜尋回傳僅含淨值與期間報酬，**無風險欄位**。
- `POST /api/offshore/fund-basic/query-details` 提供 **RR 風險報酬等級（RR1–RR5）**、**資產類別**（股票型／固定收益型／平衡型…）、投資類型；實測數字／英數／長碼基金代碼皆正常。
- 期間報酬離散度與長期報酬無關（r≈0.09），但與最大單期虧損相關（r≈0.53）→ 穩定性宜用「正報酬持續性 + 回撤」衡量，而非離散度。
- universe 內「對沖／Hedged」62 檔皆為**美元對沖（貨幣避險）級別**（RR4 一般開放型基金），非對沖基金；真正的對沖基金（避險／另類）0 檔且 TDCC 無此分類。

## 決策

新初評分（總分約 100）：

```
score = 成長品質(0–35) + 穩定持續(0–35) + 收入(0–10) + 新聞(0–10) + 風險調整(RR −8~+3) + 槓桿懲罰(−15)
```

1. **成長品質（0–35）**：長期報酬加權（6M 0.15／1Y 0.30／2Y 0.25／3Y 0.30，不含 1M/3M 短線），`35×(1−e^(−lt/40))` **報酬遞減**——高獲利不碾壓穩定型（100%→200% 僅差 ~2.6 分）。
2. **穩定持續（0–35）**：
   - 長期持續正報酬（0–15）：1Y/2Y/3Y 各正 +5（穩定持續獲利）。
   - 無深回撤（0–12）：最差單期 ≥5→12、≥0→9、≥−5→6、≥−15→2、<−15→0。
   - 近期未急跌（0–8）：1M>−3 且 3M>−5→8；1M>−8 且 3M>−10→5；1M>−15→2；否則 0。
3. **收入（0–10）**：沿用近 12M 配息率分級（`min(10, yield×1.5)`）。
4. **新聞（0–10）**：沿用。
5. **風險調整（RR）**：RR1 +3／RR2 +1.5／RR3 0／RR4 −4／RR5 −8。多數股票基金為 RR4，統一 −4 屬可接受之穩健傾斜。
6. **槓桿懲罰（−15）**：名稱含 `槓桿｜放空｜反向｜Inverse｜Leveraged｜Daily Nx`。**不含「對沖／Hedged／避險」**——那是貨幣避險級別，非高風險。

槓桿／對沖基金原則：真正的對沖基金（若進入 universe）由 RR＋資產類別層攔截；名稱懲罰僅保留給明確槓桿／反向工具。

## 影響

- 黃金（RR5、近月急跌）：穩定分大幅降低 → 跌出前段。
- 穩定長期成長之平衡／債券／日本股票基金：穩定分滿檔 → 霸榜。
- `breakdown` 新增 `growth_score / stability_score / risk_level / risk_bonus / leverage_penalty / long_term_return`（移除 `momentum_score / stability_bonus`；保留 `momentum()` 供新聞目標排序）。
- 資料管道每日新增 `fetch_fund_details`（全體基金，~4 分鐘）。
- 測試全量對齊新公式（140 項通過）。
