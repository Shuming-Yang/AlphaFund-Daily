# ADR-0011：新聞基金特定標記 + 雙查詢 + 低訊號過濾

狀態：已接受（2026-08-01）

## 情境

M1 新聞以「系列關鍵字」抓取與匹配（如「瀚亞投資」「聯博」），導致：
- **跨基金污染**：聯博國際科技基金被「聯博非投資等級債券」新聞污染；百達被「百達-KY（股票）」「百達攝影獎」污染。
- **導流頁充斥**：395 筆池中 50% 為「總覽/淨值」導流頁（鉅亨基金老司機、CMoney 淨值與總覽、TAROBO）與例行公告（召開股東常會、新增上架），訊號弱。
- **news_volume 失真**：777/2128 檔靠系列名匹配獲得新聞，新聞聲量維度（0–15）膨脹且不精準。

## 決策

1. **抓取雙查詢**（`news.py`）：
   - `fund_keyword`：**基金特定關鍵字**（`fund_distinctive`＝連字號後段標的，如「日本動力」「國際科技」；後段全為級別時退系列）。
   - `series_keyword`：系列主名稱（同系列僅查一次，補召回）。
2. **低訊號過濾**（`is_low_signal`）：排除 總覽/淨值/基金老司機/爆料同學會/召開股東常會/新增上架/接受申購 樣式，與 ezfunds.com.tw / TAROBO / 股市爆料 來源、平台廣告。
3. **匹配分層**：
   - `news_volume`（計分）：僅**基金特定匹配**（`fund_matches_title`）→ 消除跨基金污染。
   - `related_news`（LLM 新聞摘要）：先基金特定；無則退系列層（`fund_matches_series`）→ 保住深度分析新聞來源。

## 影響

- 本機實抓（2026-08-01，動能前 25 檔）：57 筆、**0 低訊號殘留**，來源含工商時報/經濟日報/鉅亨買基金等真實報導（如「富坦生技領航基金十度在台獲獎」）。
- news_score 更嚴格（有新聞基金由 777 → ~243/2128），新聞維度更誠實，主訊號回歸動能。
- 深度基金若無基金特定新聞，退系列層，仍無則顯示「無相關新聞」。
- 抓取成本：每檔至多 2 次查詢（workflow `--news-limit 200` 約 +3 分鐘）。
