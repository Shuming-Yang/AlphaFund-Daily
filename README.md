# AlphaFund-Daily — 每日 AI 境外基金投研與優選報告

![Last Commit](https://img.shields.io/github/last-commit/Shuming-Yang/AlphaFund-Daily)
![License](https://img.shields.io/badge/license-MIT-blue)
![Repo Size](https://img.shields.io/github/repo-size/Shuming-Yang/AlphaFund-Daily)
![Top Language](https://img.shields.io/github/languages/top/Shuming-Yang/AlphaFund-Daily)

每日自動化的境外基金投資研究與優選報告系統。本專案於每日清晨自動掃描指定金融通路所上架的境外基金，整合全球財經新聞進行資訊過濾，透過 AI 模型執行價值評分、購入模式分析與優劣勢評估，最終產出結構化的每日報告頁面，幫助投資人快速掌握投資契機與稅務效益。

本文件為專案之完整規格說明，涵蓋標的範圍、篩選機制、運作流程、評分框架、稅務說明與開發路線圖。詳細實作細節將以「grill-with-docs」技能逐步展開規劃。

---

## 專案簡介

全球境外基金數量龐大、級別繁雜，一般投資人難以每日追蹤淨值變動、財經新聞與稅務影響。AlphaFund-Daily 將此流程自動化：

- 每日自動取得基金淨值與績效資料，不需人工查詢。
- 自動檢索與標的相關的近 24 小時財經新聞，並過濾雜訊。
- 以 AI 模型進行量化評分與質化分析，產出一致性高、可比較的每日報告。
- 所有篩選與建議均鎖定於「投資人實際可購買、且具稅務優勢」的標的。

## 核心目標與設計原則

| 原則 | 說明 |
| :--- | :--- |
| 自動化 | 每日排程執行，無人值守，晨間產出最新報告。 |
| 精準篩選 | 非全市場盲抓，以三重硬性條件鎖定具落地可行性的標的。 |
| 稅務導向 | 標的限定為真正境外基金，凸顯最低稅負制下的稅務優勢。 |
| 落地可行 | 分析結果可直接於使用者既有之證券或銀行帳戶下單。 |
| 合規 | 所有分析僅供研究參考，內建免責聲明，不構成投資建議。 |

## 標的範圍與硬性篩選條件

本專案透過三重過濾機制，將全市場數千支境外基金收斂至可操作、可追蹤、具稅務效益的目標清單。

### 銷售通路

限定以下三家通路所上架的境外基金：

| 通路 | 角色 |
| :--- | :--- |
| 元大證券 | 兼具複委託與基金銷售通路 |
| 匯豐銀行 | 外資銀行，以國際大型基金公司產品為主 |
| 渣打銀行 | 外資銀行，以國際大型基金公司產品為主 |

此限制確保報告中的每一檔基金，均可在使用者現有的證券或銀行帳戶中直接購買，避免「分析有餘、購買無門」的問題。

### 計價幣別

僅保留美金（USD）級別（Share Class）。

TDCC 境外基金資料無新臺幣（TWD）級別（見 ADR-0004），故幣別過濾僅含 USD；並排除南非幣、澳幣、歐元、人民幣、日圓等高匯率波動或非主流幣別，聚焦於市場主流儲備與交割幣別，降低匯率雜訊對評分的干擾。

### 稅務類別（100% 境外所得）

嚴格限定基金註冊地於海外之「真正境外基金」：

- 基金 ISIN Code 不得以「TW」開頭（如盧森堡 LU、愛爾蘭 IE、開曼 KY 等）。
- 基金註冊地（Domicile）不得為台灣。
- 排除境內投信發行之海外基金。

符合上述條件之基金，其買賣價差（資本利得）與配息均歸類為「海外所得」，適用《所得基本稅額條例》（最低稅負制）。

### 排除條件彙整

| 條件 | 排除內容 |
| :--- | :--- |
| 通路 | 非上述三家通路銷售之基金 |
| 幣別 | 非 USD 之級別 |
| 註冊地 | 台灣註冊、TW 開頭 ISIN 之基金 |
| 收入屬性 | 非 100% 境外所得之標的 |

## 每日運作流程（AM 06:00）

每日上午 06:00 自動執行以下四個階段，產出當日報告。

### 階段一：數據採集

- 自公開資料來源取得目標基金之每日最新淨值與近期績效。
- 比對既有目標清單，更新基金上架狀態與通路資訊。
- 套用硬性過濾器，確認幣別、註冊地與通路符合條件。

### 階段二：新聞收集與過濾

- 針對納入分析之基金，檢索近 24 小時內相關之財經新聞。
- 過濾重複內容與非關聯報導，僅保留與基金標的、持股產業或區域相關之資訊。
- 初步標記新聞情緒傾向，作為後續評分輸入。

### 階段三：AI 分析

- 新聞重點摘要與市場情緒分類（正面 / 中立 / 負面）。
- 依評分矩陣計算 0–100 分「AI 價值評分」，並說明給分理由。
- 依波動度與趨勢判定購入模式建議。
- 產出客觀優劣勢分析與稅務配置提示。

### 階段四：排名與報告產出

- 將全體分析結果彙整為排名清單與個案解讀。
- 轉換為易於閱讀之每日靜態網頁報告。
- 更新報告首頁，提供排名表單、優劣說明與購入模式推薦。

## 評分矩陣與分析指標

每日報告之綜合評級採用多維度加權設計：

| 評分維度 | 權重 | 評估內容 |
| :--- | :---: | :--- |
| 總體經濟與產業風向 | 40% | 近 24 小時新聞關注度、央行利率政策、產業趨勢利多程度 |
| 績效與風險表現 | 40% | 近期淨值走勢、同類別相對績效、抗跌與穩定度 |
| 市場情緒與資金流向 | 20% | 新聞媒體與機構報告之聲量及情緒傾向 |

### 綜合評級分類

| 評級 | 意義 |
| :--- | :--- |
| 強力推薦 | 多項指標同時轉佳，趨勢明確 |
| 值得關注 | 具潛力但仍有待確認因素 |
| 中立觀望 | 訊號分歧，維持觀察 |
| 暫時避開 | 負面訊號明顯，風險偏高 |

### 購入模式建議

| 建議模式 | 適用情境 |
| :--- | :--- |
| 定期定額（DCA） | 波動度偏高但長期趨勢看好 |
| 分批單筆 | 打底完成、趨勢明確且波動收斂 |
| 觀望（Hold / Wait） | 訊號不明或負面風險未除 |

## 稅務與資產配置說明

本專案所收錄之標的均符合臺灣《所得基本稅額條例》（最低稅負制）規範，其資本利得與配息 100% 歸類為海外所得。

### 三大稅務優勢

1. 100 萬免申報門檻：全戶全年海外所得未達新臺幣 100 萬元者，無須計入基本所得額。
2. 750 萬免稅額度：全年海外所得滿 100 萬元者，合併其他基本所得額後，享有每年 750 萬元免稅額度。
3. 免二代健保：境外基金配息免扣取 2.11% 二代健保補充保費。

### 累積型與配息型差異

| 級別類型 | 特性 | 建議應用 |
| :--- | :--- | :--- |
| 累積型（Acc） | 收益再投資，價差延後實現 | 追求長期資產增長，避免年度海外配息超過免申報門檻 |
| 配息型（Dis） | 產生即時海外所得現金流 | 活用每年 100 萬免申報門檻與 750 萬免稅額度 |

### 適用對象

本專案標的之稅務優勢特別適合綜合所得稅率位於 20%–40% 級距、有海外資產配置需求之高資產投資人，作為稅務規劃工具參考。

## 報告呈現架構

每日報告頁面應包含以下內容模組：

- 全體標的之排名表單（依 AI 價值評分排序）。
- 個案深度解讀：新聞摘要、評分理由、購入模式與優劣勢說明。
- 稅務標籤：境外所得類別、免扣二代健保、適用免稅額度標示。
- 通路提示：於何通路購買可能享較佳手續費或優惠。
- 報告日期與資料來源聲明。

## 自動化與品質要求

- 兩階段過濾控制成本：先以規則（漲跌幅、新聞聲量、資金流）篩選出重點基金，再送交 AI 深度分析，控制 LLM Token 消耗。
- 輸出一致性：AI 分析須依固定評分矩陣與結構化格式輸出，確保每日報告格式穩定、利於比較。
- 資料來源穩定性：優先採用結構穩定之公開資料來源，降低因網站改版造成的維護成本。
- 異常處理：資料抓取失敗、淨值缺漏或新聞短缺時，須有降級或告警機制，避免產出內容不全之報告。

## 金融合規與免責聲明

1. 非投資建議：本專案產出之所有內容（含新聞整理、AI 價值評分、優劣勢分析與購入模式建議）均由自動化程式與人工智慧模型演算生成，僅供學術研究與個人資產管理參考，不構成任何形式之投資招攬、要約或決策依據。
2. 數據延遲：基金淨值、新聞與通路資訊均來自第三方公開管道，本專案不保證資料之即時性、完整性與絕對正確性。
3. 自負風險：投資人應獨立判斷，並審慎評估自身風險承受度與稅務狀況。投資境外基金存在匯率風險與市場波動風險，過去之績效不代表未來績效之保證。
