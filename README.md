每日自動化的境外基金投資研究與優選報告系統。本專案於每日清晨自動掃描指定金融通路所上架的境外基金，整合全球財經新聞進行資訊過濾，透過 AI 模型執行價值評分、購入模式分析與優劣勢評估，最終產出結構化的每日報告頁面，幫助投資人快速掌握投資契機與稅務效益。

本文件為專案之完整規格說明，涵蓋標的範圍、篩選機制、運作流程、評分框架、稅務說明與開發路線圖。詳細實作細節將以「grill-with-docs」技能逐步展開規劃。

## 專案簡介

全球境外基金數量龐大、級別繁雜，一般投資人難以每日追蹤淨值變動、財經新聞與稅務影響。AlphaFund-Daily 將此流程自動化：

- 每日自動取得基金淨值與績效資料，不需人工查詢。
- 自動檢索與標的相關的近 24 小時財經新聞，並過濾雜訊。
- 以 AI 模型進行量化評分與質化分析，產出一致性高、可比較的每日報告。
- 所有篩選與建議均鎖定於「投資人實際可購買、且具稅務優勢」的標的。

## 核心目標與設計原則

| 原則 | 說明 |
| :--- | :--- |
| 自動化 | 每日排程執行，無人值守，晨間產出最新報告。 |
| 精準篩選 | 非全市場盲抓，以三重硬性條件鎖定具落地可行性的標的。 |
| 稅務導向 | 標的限定為真正境外基金，凸顯最低稅負制下的稅務優勢。 |
| 落地可行 | 分析結果可直接於使用者既有之證券或銀行帳戶下單。 |
| 合規 | 所有分析僅供研究參考，內建免責聲明，不構成投資建議。 |

## 標的範圍與硬性篩選條件

本專案透過三重過濾機制，將全市場數千支境外基金收斂至可操作、可追蹤、具稅務效益的目標清單。

### 銷售通路

限定以下三家通路所上架的境外基金：

| 通路 | 角色 |
| :--- | :--- |
| 元大證券 | 兼具複委託與基金銷售通路 |
| 匯豐銀行 | 外資銀行，以國際大型基金公司產品為主 |
| 渣打銀行 | 外資銀行，以國際大型基金公司產品為主 |

此限制確保報告中的每一檔基金，均可在使用者現有的證券或銀行帳戶中直接購買，避免「分析有餘、購買無門」的問題。

### 計價幣別

僅保留美金（USD）級別（Share Class）。

TDCC 境外基金資料無新臺幣（TWD）級別（見 ADR-0004），故幣別過濾僅含 USD；並排除南非幣、澳幣、歐元、人民幣、日圓等高匯率波動或非主流幣別，聚焦於市場主流儲備與交割幣別，降低匯率雜訊對評分的干擾。

### 稅務類別（100% 境外所得）

嚴格限定基金註冊地於海外之「真正境外基金」：

- 基金 ISIN Code 不得以「TW」開頭（如盧森堡 LU、愛爾蘭 IE、開曼 KY 等）。
- 基金註冊地（Domicile）不得為台灣。
- 排除境內投信發行之海外基金。

符合上述條件之基金，其買賣價差（資本利得）與配息均歸類為「海外所得」，適用《所得基本稅額條例》（最低稅負制）。

### 排除條件彙整

| 條件 | 排除內容 |
| :--- | :--- |
| 通路 | 非上述三家通路銷售之基金 |
| 幣別 | 非 USD 之級別 |
| 註冊地 | 台灣註冊、TW 開頭 ISIN 之基金 |
| 收入屬性 | 非 100% 境外所得之標的 |

## 每日運作流程（AM 06:00）

每日上午 06:00 自動執行以下四個階段，產出當日報告。

### 階段一：數據採集

- 自公開資料來源取得目標基金之每日最新淨值與近期績效。
- 比對既有目標清單，更新基金上架狀態與通路資訊。
- 套用硬性過濾器，確認幣別、註冊地與通路符合條件。

### 階段二：新聞收集與過濾

- 針對納入分析之基金，檢索近 24 小時內相關之財經新聞。
- 過濾重複內容與非關聯報導，僅保留與基金標的、持股產業或區域相關之資訊。
- 初步標記新聞情緒傾向，作為後續評分輸入。

### 階段三：AI 分析

- 新聞重點摘要與市場情緒分類（正面 / 中立 / 負面）。
- 依評分矩陣計算 0–100 分「AI 價值評分」，並說明給分理由。
- 依波動度與趨勢判定購入模式建議。
- 產出客觀優劣勢分析與稅務配置提示。

### 階段四：排名與報告產出

- 將全體分析結果彙整為排名清單與個案解讀。
- 轉換為易於閱讀之每日靜態網頁報告。
- 更新報告首頁，提供排名表單、優劣說明與購入模式推薦。

## 評分矩陣與分析指標

每日報告之綜合評級採用多維度加權設計：

| 評分維度 | 權重 | 評估內容 |
| :--- | :---: | :--- |
| 總體經濟與產業風向 | 40% | 近 24 小時新聞關注度、央行利率政策、產業趨勢利多程度 |
| 績效與風險表現 | 40% | 近期淨值走勢、同類別相對績效、抗跌與穩定度 |
| 市場情緒與資金流向 | 20% | 新聞媒體與機構報告之聲量及情緒傾向 |

### 綜合評級分類

| 評級 | 意義 |
| :--- | :--- |
| 強力推薦 | 多項指標同時轉佳，趨勢明確 |
| 值得關注 | 具潛力但仍有待確認因素 |
| 中立觀望 | 訊號分歧，維持觀察 |
| 暫時避開 | 負面訊號明顯，風險偏高 |

### 購入模式建議

| 建議模式 | 適用情境 |
| :--- | :--- |
| 定期定額（DCA） | 波動度偏高但長期趨勢看好 |
| 分批單筆 | 打底完成、趨勢明確且波動收斂 |
| 觀望（Hold / Wait） | 訊號不明或負面風險未除 |

## 初評分（Preliminary Score）計算規則

每日排名以「初評分」為依據，由程式規則對全體目標基金計算（`scoring.py`）。評分設計以**穩定導向**為核心——穩定獲利 > 高獲利、穩定持續獲利 > 短期高獲利、穩定成長 > 高波動（詳見 [ADR-0012](./docs/adr/0012-stable-risk-adjusted-scoring.md)）。

```
初評分 = 成長品質(0–35) + 穩定持續(0–35) + 收入加分(0–15) + 新聞聲量(0–5) + DCA加分(0–10) + 風險調整(RR −8~+3) + 槓桿懲罰(−15)
```

### 1. 成長品質（0–35）— 穩定成長，報酬遞減

長期報酬加權（**不含短線 1M/3M**）：`6M×0.15 + 1Y×0.30 + 2Y×0.25 + 3Y×0.30`，再以指數函數**報酬遞減**避免高獲利碾壓穩定型：

```
成長品質 = 35 × (1 − e^(−長期報酬% / 40))
```

換算：長期報酬 8% → 6.9 分、25% → 16.4 分、50% → 24.5 分、100% → 31.8 分、200% → 34.4 分。長期報酬為負 → 0 分。

### 2. 穩定持續（0–35）— 穩定持續獲利、無深回撤

| 子項 | 配分 | 計算 |
| :--- | :---: | :--- |
| 長期持續正報酬 | 0–15 | 1Y/2Y/3Y 各為正報酬 +5 |
| 無深回撤 | 0–12 | 最差單期 ≥+5%→12、≥0%→9、≥−5%→6、≥−15%→2、<−15%→0 |
| 近期未急跌 | 0–8 | 1M>−3% 且 3M>−5%→8；1M>−8% 且 3M>−10%→5；1M>−15%→2；否則 0 |

### 3. 收入加分（0–15）— 有效配息率 + 品質分級保底

配息率以「**有效配息率**」計（`models.py`）：

```
有效配息率 = 名目配息率（近 12M Σ每單位配息 ÷ 最新淨值）× 收益品質
收益品質（income_quality，0–1）= 配息金額加權平均「收益來源比例」；缺本金/收益比例之紀錄視為 50% 收益
```

**本金占比高的基金，其「配息率」被折扣**（配息來源含本金 = 返還本金，非真實收益）：

```
收入加分 = max( min(15, 有效配息率 × 2.0), 四級保底 )
```

| 保底情境 | 保底分 | 說明 |
| :--- | :---: | :--- |
| 完整（資料齊全且非全本金） | 7 | 每筆配息皆有來源比例，且非全本金 |
| 無配息資料（配息型） | 5 | 名稱判為配息型但無配息紀錄 |
| 折半（有配息但缺比例資料） | 4 | 部分/全部配息缺來源比例 |
| 真本金（資料齊全且全本金） | 3 | 每筆配息來源皆為 100% 本金 |

有效配息率 7.5% 即達上限 +15；配息基金均有基本加分（不歸零）。

### 4. 新聞聲量（0–5）

`min(5, 近 7 日與基金特定相關新聞數 × 1)`（5 則封頂），僅計基金特定匹配新聞，消除跨基金污染。新聞為短期雜訊，配分低。

### 5. DCA 定期定額加分（0–10）— 實際投入體驗

模擬「每月投資 100 美金、為期 12 個月」之定期定額體驗（**推估**，非真實歷史淨值）：

```
DCA 年報酬% = (期末總值 + 配息現金 − 1200) ÷ 1200 × 100
期末總值   = 累計買入單位 × 最新淨值；配息依月份以當時持有單位計現金（不再投資）
路徑       = 以 1M/3M/6M/1Y 期間報酬錨點在 log 空間內插出過去 12 個月淨值
```

```
DCA加分 = clamp(DCA年報酬% × 0.4, 0, 10) × (穩定持續分 ÷ 35)
```

- 報酬 25% 達滿分；負報酬無加分。
- **穩定性門控**：乘穩定持續分，V 型高波動基金即使 DCA 報酬高也被打折（符合「穩定成長 > 高波動」）。

### 6. 風險調整（−8~+3）— RR 風險報酬等級

資料源：TDCC `fund-basic/query-details` 之風險報酬等級（RR1–RR5）。

| RR | RR1 | RR2 | RR3 | RR4 | RR5 |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 調整 | +3 | +1.5 | 0 | −4 | −8 |

高風險（RR4/RR5）不適合長期投資 → 扣分；低風險（RR1/RR2）加分。

### 7. 槓桿懲罰（−15）

名稱含 `槓桿｜放空｜反向｜Inverse｜Leveraged｜Daily Nx` 之槓桿/反向工具 → −15。**「對沖/Hedged」為貨幣避險級別（非對沖基金）不懲罰**。

### 可調整參數（環境變數）

`GROWTH_MAX`、`GROWTH_DECAY`、`STABILITY_MAX_NEW`、`INCOME_BONUS`、`INCOME_YIELD_PER_POINT`、`INCOME_QUALITY_UNKNOWN`、`INCOME_BONUS_COMPLETE_FLOOR`、`INCOME_BONUS_NO_DATA_FLOOR`、`INCOME_BONUS_MISSING_FLOOR`、`INCOME_BONUS_PRINCIPAL_FLOOR`、`DCA_BONUS_MAX`、`DCA_RETURN_PER_POINT`、`DCA_INVEST_MONTHLY`、`RISK_BONUS_RR1..RR5`、`LEVERAGE_PENALTY`。

### 排名

初評分 ↓ → 長期報酬 ↓ → 名稱 ↑（確定性、可重現）。前段基金再送 LLM 深度分析（40/40/20 價值評分），最終呈現綜合評級。

## 稅務與資產配置說明

本專案所收錄之標的均符合臺灣《所得基本稅額條例》（最低稅負制）規範，其資本利得與配息 100% 歸類為海外所得。

### 三大稅務優勢

1. 100 萬免申報門檻：全戶全年海外所得未達新臺幣 100 萬元者，無須計入基本所得額。
2. 750 萬免稅額度：全年海外所得滿 100 萬元者，合併其他基本所得額後，享有每年 750 萬元免稅額度。
3. 免二代健保：境外基金配息免扣取 2.11% 二代健保補充保費。

### 累積型與配息型差異

| 級別類型 | 特性 | 建議應用 |
| :--- | :--- | :--- |
| 累積型（Acc） | 收益再投資，價差延後實現 | 追求長期資產增長，避免年度海外配息超過免申報門檻 |
| 配息型（Dis） | 產生即時海外所得現金流 | 活用每年 100 萬免申報門檻與 750 萬免稅額度 |

### 適用對象

本專案標的之稅務優勢特別適合綜合所得稅率位於 20%–40% 級距、有海外資產配置需求之高資產投資人，作為稅務規劃工具參考。

## 報告呈現架構

每日報告頁面（docs/index.html，GitHub Pages 發布）包含：

- **基金排名表**：依初評分排序之前 500 名；欄位＝排名、基金名稱（含代號）、初評分、通路 icon；支援名稱/代號搜尋與通路篩選。
- **個案深度解讀**：前段基金之可折疊卡片，含新聞摘要、評分理由、深度分數、評級、購入模式、優劣勢、稅務標籤與近期趨勢。
- **歷史日曆**：月曆界面瀏覽每日歷史報告（docs/archive/）。
- **趨勢比較**：個案趨勢圖與多日並排比較（docs/trends.html）。
- **完整排名**：全體基金排名表（docs/ranking.html）。
- **系統健康**：每日執行狀態與 LLM 供應商使用分布（docs/health.html）。
- **稅務說明與免責聲明**：境外所得類別、免扣二代健保、適用免稅額度標示與資料來源。

## 自動化與品質要求

- 兩階段過濾控制成本：先以規則（漲跌幅、新聞聲量、資金流）篩選出重點基金，再送交 AI 深度分析，控制 LLM Token 消耗。
- 輸出一致性：AI 分析須依固定評分矩陣與結構化格式輸出，確保每日報告格式穩定、利於比較。
- 資料來源穩定性：優先採用結構穩定之公開資料來源，降低因網站改版造成的維護成本。
- 異常處理：資料抓取失敗、淨值缺漏或新聞短缺時，須有降級或告警機制，避免產出內容不全之報告。

| [analyzer.py](src/alphafund/analyzer.py) | 深度分析 Prompt 與回應解析：40/40/20 評分矩陣、評級一致性校準（ADR-0010） |
| [pipeline.py](src/alphafund/pipeline.py) | 管線編排：M1 資料快照 → M2 分析 |
| [report.py](src/alphafund/report.py) | HTML 報告、完整排名、趨勢頁生成 |
| [trends.py](src/alphafund/trends.py) | 歷史時序 + 行內 SVG 趨勢圖（ADR-0008，無 JS 依賴） |
| [health.py](src/alphafund/health.py) | 系統健康頁：每日執行狀態 + LLM 供應商使用分布 |
| [cli.py](src/alphafund/cli.py) | `alphafund` 命令列入口（m1 / m2 / daily / report / archive / ranking / trends / health / universe） |

### 每日資料流

1. **M1 資料採集**（[pipeline.run_m1](src/alphafund/pipeline.py#L148-L191)）：依三通路 org_code 查上架基金 → 抓取全部境外基金記錄 → `filter_funds` 收斂為目標清單 → 抓取配息型候選之配息紀錄與全體風險等級 → Google News 依關鍵字抓新聞 → 存 `data/history/<date>/`（gzip JSON 快照）。
2. **M2 分析**（[pipeline.run_m2](src/alphafund/pipeline.py#L317-L358)）：載入快照 → 全體基金規則初評分並確定性排序（初評分 ↓ → 長期報酬 ↓ → 名稱 ↑）→ 前段基金送 LLM 深度分析（供應商鏈自動備援）→ 存 `analysis.json.gz`。
3. **M3+ 報告**：讀取 analysis + nav → 產出 `docs/index.html`（排名表 + 個案卡片 + 月曆）、`ranking.html`、`trends.html`、`health.html`、`archive/<日期>.html`。

### 設計要點

- **兩階段評分（ADR-0003）**：先以規則初評分篩選前段，再送 LLM 深度分析，控制 Token 成本並維持輸出一致性。
- **穩定導向（ADR-0012）**：成長報酬以指數函數遞減、DCA 加分乘穩定性門控，確保「穩定成長 > 高波動」。
- **可重現性**：初評分為純函式、排名排序確定、趨勢圖為伺服器端 SVG（無 JS 依賴），全流程可單元測試。
- **成本控制（ADR-0002 / ADR-0007）**：LLM 全採免費 tier（openrouter → gemini → groq → cloudflare → nvidia），429/401/403 自動切換備援，全數用罄才停。
